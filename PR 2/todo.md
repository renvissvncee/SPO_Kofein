# Распределение задач

## Артем — Проектирование базы данных

- Определить основные сущности и их атрибуты.
- Определить связи между сущностями.
- Спроектировать структуру базы данных.
- Создать ER-диаграмму.
- Создать таблицы БД и необходимые ограничения.
- Подготовить SQL-скрипты / миграции для создания БД.
- Добавить начальные тестовые данные.
- Проверить корректность связей и ограничений БД.
- Описать структуру БД в README.

**Результат:** готовая схема БД, ER-диаграмма, миграции/SQL и документация.

---

## Участник 2 — API-контракт и серверная логика

- Определить основные ресурсы приложения.
- Спроектировать REST API.
- Определить endpoints и HTTP-методы.
- Определить структуру запросов и ответов.
- Определить HTTP status codes и формат ошибок.
- Подготовить OpenAPI / Swagger-спецификацию.
- Реализовать базовую структуру серверного приложения.
- Реализовать основные CRUD endpoints.
- Проверить соответствие реализации API-контракту.

**Результат:** рабочий REST API, OpenAPI/Swagger и базовая серверная логика.

---

## Участник 3 — Аутентификация и безопасность

- Реализовать регистрацию пользователя.
- Реализовать авторизацию пользователя.
- Реализовать JWT-аутентификацию.
- Реализовать middleware для проверки JWT.
- Настроить авторизацию и проверку прав доступа.
- Реализовать безопасное хранение паролей.
- Добавить валидацию входных данных.
- Реализовать обработку ошибок 401/403.
- Проверить, что защищённые endpoints недоступны без корректного JWT.
- Написать тесты для аутентификации и авторизации.

**Результат:** работающая JWT-аутентификация, защита API и тесты безопасности.

---

## Участник 4 — Тестирование и CI/CD

- Подготовить unit-тесты для основной бизнес-логики.
- Подготовить интеграционные/API-тесты.
- Проверить основные CRUD-сценарии.
- Проверить обработку ошибок и граничных случаев.
- Настроить линтер.
- Настроить CI/CD pipeline.
- Добавить автоматический запуск линтера и тестов.
- Настроить сборку проекта в CI.
- Проверить, что pipeline завершается ошибкой при падении тестов или линтера.
- Подготовить инструкцию по запуску проекта и тестов.

**Результат:** набор unit/integration-тестов, настроенный CI/CD и инструкция по запуску.

---

# Общие задачи команды

После выполнения индивидуальных задач все участники совместно:

- Проверяют интеграцию всех частей проекта.
- Проверяют соответствие API контракту.
- Проверяют работу CRUD.
- Проверяют JWT-аутентификацию.
- Запускают все тесты.
- Проверяют работу CI/CD pipeline.
- Исправляют ошибки интеграции.
- Обновляют README.
- Подготавливают проект к демонстрации.
